# Algorithm Design Playground

ALGO_GRID v1.0 is an interactive, visually stunning platform for visualizing and analyzing algorithms across three major categories: **Divide & Conquer**, **Greedy Algorithms**, and **Dynamic Programming**. 

Built with a futuristic "command center" aesthetic, the playground features interactive visualizers, code syntax highlighting, and mathematical recurrence modeling.

## Technologies Used
- React + Vite
- Vanilla CSS (Glassmorphism, 3D CSS perspective transforms, neon variables)
- Lucide React (Iconography)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Future Improvements

To take the Algorithm Design Playground to the next level, the following improvements are planned:

- **Complex State Stepping:** Implement granular pause/play, forward/backwards stepping controls for all visuals.
- **Custom Input Data:** Allow users to input their own data arrays, string pairs, or graph definitions for visualizations.
- **Tree Visualization Module:** Build interactive D3/SVG trees explicitly for Huffman Coding and Recursion Trees.
- **Algorithm Sandbox Mode:** Add a live coding editor environment alongside the visualization, where users can tweak the algorithm and see the changes reflected in real-time.
- **Mobile Responsiveness:** Deeply refactor the 3D grid CSS to be fully responsive for vertical viewing on mobile devices without breaking the perspective layouts.
- **Performance Profiling Benchmarks:** Add a live benchmarking tool to trace precise JavaScript execution times matching the estimated Time Complexities.
